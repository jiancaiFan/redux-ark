# Changelog

All notable changes to redux-ark are documented in this file.

## 1.0.0 - 2026-08-30

### Added

- ArkTS implementation of the Redux 5.0.1 core behavior for HarmonyOS.
- Store creation, reducer composition, middleware, action binding, and function composition APIs.
- Concurrent store support for HarmonyOS application scenarios.
- ArkTS-compatible action, reducer, middleware, store, subscription, and observable types.
- HarmonyOS ArkUI integration guidance and complete usage examples.
